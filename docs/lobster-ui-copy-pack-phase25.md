# Lobster UI 文案包（Phase 2.5）

> 用于主题文案统一与 A/B 测试。当前已接入 `src/theme.js` 的文本映射。

## 1) 大厅（Home）
- 标题：`龙虾帝国 · 对战演练场`
- 低版本提示：`你的微信版本过低，无法运行龙虾主题演示。`
- 创建房间提示：`正在创建虾房...`

## 2) 房间（Room）
- 房间标题：`龙虾1V1对战`
- 空位文案：`点击邀请虾友`
- 离开确认：`是否离开虾房？`
- 未全员就绪提示：`全员就绪后才能开战`
- 分享标题：`龙虾帝国对战邀请`

## 3) 对战（Battle）
- 离开确认：`离开虾房会结束当前对战，确认离开吗？`
- 对手离开：`对手已离开虾房，无法继续对战。`
- 血量标签：`耐久值：`
- 倒计时模板：`开战倒计时 {count} 秒`

## 4) 结算（Result）
- 标题：`龙虾对战结算`
- 胜利字样：`胜利`
- 按钮文案：`返回大厅`

## 5) 系统（Server）
- 连接恢复：`游戏已连接`
- 掉线提示：`游戏已掉线...`
- 匹配成功：`匹配成功！3秒后开始龙虾对战`
- 对局时长：`对局时长: {sec}s`
- 重连确认：`检测到未结束对局，是否重连继续？`
- 重连失败：`重连失败，请重新开房间`
- 匹配中昵称：`正在匹配虾友...`

## 6) 语气规则
- 轻松但不低幼，避免夸张承诺
- 统一“龙虾帝国”世界观词汇
- 提示语尽量短，避免遮挡主要UI
