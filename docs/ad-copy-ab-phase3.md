# 激励广告文案 A/B（Phase 3）

## 开关与位置
- 文案函数：`src/theme.js -> themedAdText()`
- 变体开关：`src/theme.js -> AD_COPY_VARIANT`（A / B）
- UI入口开关：`src/config.js -> adUiEnabled`（默认 false）

## A/B 文案表

| 场景 | A版 | B版 |
|---|---|---|
| 复活按钮 | 看广告立即复活 | 再战一次（激励视频） |
| 双倍按钮 | 看广告领双倍虾币 | 奖励翻倍（激励视频） |
| 复活说明 | 观看激励视频后，可获得一次继续对战机会。 | 完成激励视频可返场继续挑战。 |
| 双倍说明 | 观看激励视频后，本局结算奖励翻倍。 | 完成激励视频可获得本局双倍结算。 |

## 建议实验
1. 先用 A 跑 3 天，记录点击率/完播率
2. 再用 B 跑 3 天，保持其他变量不变
3. 比较：按钮点击率、完播率、ARPDAU
