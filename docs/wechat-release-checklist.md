# WeChat Mini Game 发布清单（广告变现版）

## 1) 合规与版权
- [ ] 第三方代码许可可商用（MIT/Apache/BSD）
- [ ] 美术/音效素材有可追溯授权
- [ ] 隐私政策链接可访问
- [ ] 未使用违规关键词、诱导分享文案

## 2) 广告接入（激励视频）
- [ ] 配置正式 `adUnitId`
- [ ] 广告加载失败有降级策略（不发奖励）
- [ ] 每局激励广告上限（建议 <=2）
- [ ] 不强制看广告才能开始第一局

## 3) 体验与性能
- [ ] 首帧可用时间可接受（冷启动）
- [ ] 中低端机 FPS 稳定
- [ ] 弱网下可回退/重试
- [ ] 断线、返回前台、切后台恢复正常

## 4) 提审材料
- [ ] 游戏描述（真实、不过度承诺）
- [ ] 截图（玩法、UI、结算、广告位说明）
- [ ] 测试账号/测试路径
- [ ] 合规声明（仅模拟奖励、无赌博导向）
