# 微信小游戏提审文案模板（Phase 2.5）

## 一、游戏简介（可直接粘贴）
《龙虾帝国对战》是一款轻量休闲 1v1 对战小游戏。玩家可创建房间或快速匹配，控制角色移动与攻击，在短局对战中完成策略博弈。游戏节奏快、上手简单，适合碎片化体验。

## 二、核心玩法
1. 创建房间或匹配进入对战
2. 通过摇杆移动，点击技能按钮攻击
3. 在有限耐久内击败对手获得胜利

## 三、付费/广告说明（激励视频）
- 游戏提供激励视频广告位（如复活/奖励倍增）
- 广告为可选，不强制观看后才能开始首局
- 若广告加载失败，不会异常发放奖励

## 四、隐私与合规声明
- 游戏不涉及赌博或现金交易
- 不包含违法违规内容
- 用户数据处理遵循平台规范并提供隐私说明页面

## 五、测试指引（审核同学）
1. 进入首页，点击“创建房间”或“快速匹配”
2. 进入房间后开始对战
3. 体验移动、攻击、结算、返回大厅全流程
4. 在结算/指定节点测试激励视频入口（如已开启）
